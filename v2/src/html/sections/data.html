Backup, import, export and privacy

You can always leave with a copy, go back to an earlier state, or erase everything.

Guide · backup and privacy

What: Portable, versioned local files. How: Export a full private backup for your own device (optionally encrypted with a passphrase) or a redacted summary for sharing. Import only trusted, readable JSON files. Outcome: You keep an independent copy. Browser storage can be cleared; an exported backup is strongly recommended. Plain JSON backups are NOT encrypted; use the encrypted option for anything sensitive.

Export workspace

Default exports redact project descriptions, task descriptions and observation notes, rotate record IDs, and omit genome records and toolkit records that were not marked shareable. A full backup contains private text, so store it securely. Numbers and dates can still be identifying; review before sharing.

Encrypted backups use a passphrase you choose (PBKDF2 + AES-GCM in your browser). If you lose the passphrase, nobody, including us, can recover the file. Redacted exports are REDACTED, not guaranteed anonymous.

Import workspace

Schema v1, v2 and v3 files are accepted. A restore point is saved before every import. Imported text is validated, size-limited and rendered as text, never as HTML.

Restore points

Automatic snapshots are taken before imports, conflicts and every few minutes of editing. They live in this browser only.

Storage & persistence

Your v3 data was copied into v4 and left untouched. Delete the old copies once you have verified your workspace.

Data lifecycle

  • No cookies, trackers, hidden telemetry or remote API calls. Optional local-only counters are off by default and viewable in System check.
  • IndexedDB is preferred; a LocalStorage fallback has smaller capacity; file:// access has browser-dependent persistence.
  • All UI, code and research notes are embedded in this file, so first load works offline.
  • Links to external publishers open only when you click.
  • Optional internet features (rooms, local-model download) ask first and are listed in System check › Network transparency.

Install & offline cache (hosted copies only)

Opening index.html from a file already works offline. If you host this folder on HTTPS or localhost, you can optionally register a service worker to cache it and install it like an app. Nothing is registered unless you press the button.

Security: do not paste sensitive case records into public AI tools. Check copyright, licensing and permissions before redistributing material.
