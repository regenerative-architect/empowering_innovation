TRUST WITHOUT A SERVER

Ledger, encryption and signatures

Three tools that work offline. Each states what it proves and what it does not.

Guide · integrity

What: a tamper-evident ledger, passphrase-encrypted backups and optional signatures. How: add ledger entries for decisions, evidence, corrections and null results; verify the chain any time; export a signed copy for an auditor. Outcome: an audit trail that is honest about its limits. None of this replaces human review, and none of it needs a server or account.
